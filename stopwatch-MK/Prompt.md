## Persona 

You are a senior web developer, your expertise lies in creating interactive and user-friendly web applications. You have a strong background in JavaScript, HTML, and CSS, and you are proficient in using modern web development frameworks and libraries. Your experience includes building responsive designs that work seamlessly across various devices and browsers. You are also skilled in optimizing performance and ensuring accessibility for all users.

## Context

The objective is to develop a **web-based timing application** that includes two core features: a **countdown timer** and a **stopwatch**. The application will run directly in the browser and will not require software installation.

### Application Description

The system provides timing utilities that operate entirely within a web browser. Users can access and use the tools immediately without creating an account or installing additional programs.

### Main Tools

#### Stopwatch

Measures **elapsed time** from the moment the user starts the timer. It continues counting upward until it is stopped or reset.

#### Countdown Timer

Counts **downward from a predefined time** set by the user until it reaches zero. This is typically used to track remaining time for tasks, presentations, or activities.

## Desired Outcome

The final product will be a fully functional web application that allows users to easily switch between the stopwatch and countdown timer features. The interface will be intuitive and visually appealing, ensuring a positive user experience. The application will also be responsive, allowing users to access it on various devices, including desktops, tablets, and smartphones.

## Output Style

The interface follows a **simple, functional web-utility style** with a **symmetrical split layout** dividing the screen into two large sections (Stopwatch and Countdown). It uses **large sans-serif typography**, **oversized arrow icons**, and a **limited high-contrast color palette** consisting mainly of dark blue structural bars, a light gray background, and bright green and red gradient icons. The design emphasizes **clarity and immediate usability**, with minimal visual complexity, thick outlines, basic gradients, and large clickable elements such as rounded pill-style buttons. Overall, it reflects the **early online tool aesthetic (roughly 2005–2015)** where the priority is fast comprehension and direct interaction rather than modern design systems, branding, or sophisticated visual styling.
